Under the hood

The checks matter
as much as the generation.

Retrieval from production files

73,657 chunks indexed from Houdini .hip files in ChromaDB, split by domain. The model receives examples of actual node wiring alongside the prompt.

Templates, validation and repair

Each domain has a wiring template and its own checks: ocean spectra paths, fracture output indices, and skin and skeleton connections for KineFX.

A helper layer handles node aliases and output indices. Post-processors repair recurring VEX mistakes; a static syntax gate checks code before it reaches Houdini.

Live bridge and technology

A TCP bridge connects to a running Houdini 21 session. Generated Python creates the nodes, then the graph is checked after cooking.

Python 3.12 · FastAPI · ChromaDB · sentence-transformers · Claude API · React + Vite · Houdini 21
